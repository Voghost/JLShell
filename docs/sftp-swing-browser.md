# Swing 文件面板

2026-10-14：默认 Swing 工作台的文件工具窗迁移为原生 Swing。

## 设计与交互

参考 IDEA `platform/platform-impl/src/com/intellij/openapi/fileChooser/impl/FileChooserPanelImpl.java` 的工具栏、可编辑路径、异步列表与过期请求丢弃机制，直接复用本项目 SftpService，不依赖 IntelliJ 平台运行时。

- 本地在上，远程在下，中间细分隔条可拖动，初始各占一半。单区最小高度 130 逻辑像素。
- 标题行展示名称、项目数和 Home / 上级 / 刷新 / 上传或下载 / 更多操作；项目数在窄宽度时收起。
- 路径行左侧树形按钮按需弹出懒加载目录树，自动展开并定位当前目录。单击目录节点选中，双击目录节点进入，展开箭头用于查看下级，Enter 确认，Esc 或外部点击关闭。
- 面包屑使用 `/` 分隔，去掉单独的下拉箭头。点击目录名称展开以该目录为根的下拉树，双击树节点后才导航；可双击根节点返回该级目录。空间不足时优先显示末级目录，前级收进省略菜单。编辑按钮或 Cmd/Ctrl+L 支持直接输入路径；Enter 导航、Esc 取消。
- 表格提供名称、大小、修改时间、远程权限。窄于 600 像素隐藏权限，窄于 360 像素隐藏时间，权限仍可在更多/右键菜单查看。表格支持多选、按列排序；双击文件夹或 Enter 进入，上级目录使用 Backspace，F5 刷新，F2 重命名。
- 上传/下载使用原 SftpService；支持两个列表互相拖放、系统文件拖到远程表格。延续旧页面的文件传输范围，目录通过进入后选择文件传输。同名目标替换前确认，删除前确认；本地递归删除不跟随符号链接。
- 底部统一显示进度、已传输大小、取消和操作错误，长错误信息可通过 tooltip 完整查看。远程菜单可启用跟随终端目录。

目录树使用 `IdeaComponentPopup` 承载普通 Swing 组件，复用 `IdeaPopupSurface` 的 8px 圆角、细边框与阴影。避免把 JTree 作为普通 JPopupMenu 菜单项时产生的鼠标事件拦截；双击时按命中节点明确设置选择路径，展开按钮只展开子目录。焦点离开、外部点击、Esc、宿主移动或隐藏时关闭，并移除临时事件监听器。

路径省略菜单、文件表右键菜单和更多菜单统一使用 `IdeaListPopup`；与目录树共用 `IdeaPopupSurface` 的圆角、边框、背景和阴影。菜单行与树选中行均使用内缩圆角高亮。目录树关闭默认双击展开行为，双击明确执行导航；左右箭头/展开控件保留展开折叠，Enter 确认导航。

## 线程与生命周期

文件扫描、远程目录读取、增删改和传输均在后台执行，结果投递 EDT。每一侧使用独立导航序号，快速切换时迟到结果不会覆盖新目录。当前目录成功读取后才更新路径与列表，失败时保留原内容。

Swing 文件页由 SessionWorkspaceTab 提供工厂，首次选中 Files 时创建。原有 FX 文件页在默认 Swing 路径中不初始化。断线时取消传输、停用跨端操作并标明断线；重连时重新捕获 SSH 会话与终端 cwd，并关闭旧页监听器与弹层。切换工具页或关闭工作区时收起目录弹层，关闭后不再接受异步 UI 回调。跨会话列表拖放被拒绝，避免把路径交给错误 SSH 连接。

## 验证

`SwingSftpBrowserTest` 使用临时本地目录与模拟 SFTP，验证纯 Swing 组件、上下布局、目录树定位、真实鼠标单击仅选中、双击树节点后导航、路径目录项展开树、Esc 收起、快速导航过期响应、上传/下载目的地、窄宽度、明暗主题和断线禁用。

`SshWorkspaceUiSmokeTest` 验证真实会话宿主从右侧文件按钮进入原生文件页，文件页无 JFXPanel，终端保持可见，并验证插件页面切换。
