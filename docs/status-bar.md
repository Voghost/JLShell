# 工作区底栏

底栏保持原 JLabel 的高度：当前界面字体行高 + 上下各 3px。最近活动、会话和传输详情向上弹出，不参与工作区布局。

左侧是面向用户的“最近活动”：只收集连接、连接保存、文件传输开始/完成/取消/失败等业务流程主动发布的消息。保留时间和可读结果，不接入应用根日志，不展示 Java 类名、INFO 等技术等级、traceId、堆栈或性能埋点。诊断日志继续由原有 Logback 文件输出保存。

活动列表按时间倒序，最多 200 条，每条最多 8192 字符；使用简洁的活动行替代表格与诊断详情框。连续重复状态不重复添加。新增活动时保留当前选中的条目。

右侧展示当前标签连接状态、连接时长和实际编码。传输入口仅在有活动任务时展示，不提前初始化 SFTP。无会话或断开时及时更新状态，隐藏窗口或关闭时停止刷新并移除订阅。

所有底栏弹层通过 `IdeaContentPopup` 复用已有 `IdeaPopupSurface` / `IdeaPopupWindow` 的圆角、阴影、边框和 Windows DWM 适配；支持点击外部、Esc、关闭按钮及主窗口隐藏时关闭，不主动最小化或重新激活主窗口。

验证入口：`RecentApplicationLogsTest`、`SwingStatusBarTest`、`IdeaContentPopupTest`、`SwingWorkbenchDockTest`。UI 回归检查深浅主题下保持旧底栏高度、活动消息不显示技术等级、弹层统一圆角、空会话状态及关闭不会最小化主窗口。
