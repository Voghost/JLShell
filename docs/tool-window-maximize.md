# 文件与插件面板铺满工作区

- [x] 文件（SFTP）和自定义插件共用右侧工具窗标题栏的“铺满工作区”按钮，铺满后切换成“还原面板”。使用跟随主题的单色线条图标和中英文提示。
- [x] 铺满范围仅限连接列表右侧的内容区：保留连接列表及其编辑操作，隐藏终端和底部监控；应用顶部项目、已打开会话选择器、设置及工具窗右侧导航仍可使用。
- [x] 还原时恢复终端、底部监控及原右侧分隔位置，保留连接列表的可见状态与宽度调整；不重新创建插件、文件浏览器或终端缓冲区。
- [x] 铺满后切换已打开会话：文件面板跟随目标会话，插件按插件 ID 匹配目标会话中已打开的页面，未打开该插件时回到目标会话插件列表。
- [x] 铺满时在工具窗标题旁显示当前连接标签，悬停显示完整连接名和地址。点击弹窗只列出已打开当前插件页面的会话，按插件 ID 匹配，支持搜索及切换；同名连接使用地址区分。文件和插件列表页也可从标签切换已打开的会话。
- [x] 收起面板或关闭最后一个会话时退出铺满，恢复普通工作区。重复切换保留插件编辑器中尚未保存的内容。

当前入口属于 Swing 工作台，兼容其嵌入的原生 Swing 与旧 JavaFX 插件。无需插件 SDK 改动。文件导航和远程路径跟随逻辑继续由各会话自己的文件浏览器管理。

文件、插件列表、自定义插件页面和监控分别以稳定工具 ID 保存停靠位置。拖动标题、导航按钮或底部标签可单独移动一个工具，目标包括右侧、底部左区和底部右区。底部两个区域可同时展示不同工具；同区用统一的图标文字标签切换。拖动中用蓝色区域预览落点，移出工作区或 Escape 可取消；底部标签右键也可选择位置。

布局使用版本化 `ui.workspace.toolLayout` 偏好保存工具位置、顺序、侧栏宽度、右侧工具宽度、底部高度及左右分隔比例。自定义插件按插件 ID 而非页码记忆位置，重新打开后恢复；无效配置回退默认值。“视图 → 恢复默认布局”恢复监控在底部、其他工具在右侧及默认尺寸，并更新保存值。工具移动直接重挂载原组件，保留文件浏览状态、插件编辑内容和终端缓冲区。

交互参考本地 IDEA `platform/platform-impl/src/com/intellij/toolWindow/ToolWindowDragHelper.kt` 的单工具 anchor/split 目标、高亮预览及释放提交方式，未引入 IntelliJ 平台依赖。

验证：`SwingToolWindowMaximizeTest` 在浅色和深色主题下使用真实窗口验证铺满面积、侧栏可见性和操作入口、侧栏显隐及宽度、当前连接标签、插件弹窗筛选与切换、会话选择入口、还原分隔位置、不同插件页顺序的 ID 匹配、文件页跟随、编辑器保留、面板收起及最后会话关闭；文件布局夹具不建立远程连接。原终端保留及拖动行为由 `SwingWorkbenchDockTest` 回归。新增测试也加入 Preview 的 Windows UI 步骤。

底部文件面板自动使用本地/远程左右布局，移回右侧恢复上下布局，并分别保留两种方向的分隔比例；目录、选择项和传输任务复用原实例。工具拖动采用 IDEA DragSession 的独立拖动反馈思路：非激活、半透明的图标/名称浮标跟随鼠标，另显示目标停靠文字与蓝色区域预览。Escape、无效落点释放和关闭工作台都会清理浮标并恢复光标。

## 双侧工具栏与独立底部区

对照 IDEA 的 `ToolWindowPaneNewButtonManager.wrapWithControls()`、
`ToolWindowToolbar.topStripe/bottomStripe`、`ToolWindowLeftToolbar` 和 `ToolWindowRightToolbar`：

- 左、右工具栏放在工作区分割器外层，贯穿终端区和底部工具区，延伸到状态栏上方。
- 左栏顶部保留连接列表入口；左栏底部列出停靠在底部左区的工具。
- 右栏顶部分组列出右侧工具；右栏底部列出停靠在底部右区的工具。
- 底部左、右区分别拥有收起按钮、当前工具和显隐状态。收起监控不会关闭右下文件，也不影响右侧插件。
- 点击外侧图标切换或收起对应区；铺满右侧工具期间点击底部图标会退出铺满并恢复各区，不关闭文件浏览器。
- 图标可直接拖到两侧工具栏的下半区；仍保留工作区内的左右底部预览、取消拖动和单工具移动。
- `ui.workspace.toolLayout` 继续兼容旧布局，同时保存各区显隐和当前工具；恢复默认布局会重置这些状态。

与 IDEA 相同，这里的底部左/右是 `BOTTOM + split=false/true` 两个工具区，不是把右侧所有页面整体搬下去。
`SwingToolWindowMaximizeTest` 新增深浅主题实际窗口验证：外栏贯通、各区独立收起/重新打开、铺满后切换、保留插件编辑内容。

## 2026-10-31：按实际工具区域计算拖放

进一步对照 `ToolWindowDropArea.kt`、`ToolWindowDragHelper.kt`、`AbstractDroppableStripe.kt` 和 `ToolWindowToolbar.kt`：

- 已有底部区域时直接使用它的实际矩形；已有左右分区时使用两个实际子组件的边界，不再固定按整个窗口的 35% 高度或 50% 宽度画预览。
- 没有可见底部区域时才使用四分之一高度、至少 200 的候选区域。
- 拖动图片改为约 28×28 的单色图标，目标提示是独立的单行浮层；源图标暂时隐藏绘制，释放/取消后恢复。
- 目标侧栏显示蓝色插入位，同组内拖动可调整顺序，并保存到现有布局设置。拖回自己的内容区域不会意外改变侧栏顺序。
- 图标拖影上的鼠标拖动/释放转发回拖动控制器，处理原生窗口抢到鼠标事件的情况。
- 蓝色预览只填充目标范围；释放使用同一目标区域的高度和插入位。Escape、移出后释放和关闭窗口均清理临时反馈。

`ToolDropGeometryTest` 检查真实高度、非对半分区和关闭后的候选区域；真实窗口测试检查分区预览范围、小图标拖影、分离提示、插入顺序、拖影窗口释放事件、取消和布局恢复。
