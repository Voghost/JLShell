# 文件与插件面板铺满工作区

- [x] 文件（SFTP）和自定义插件共用右侧工具窗标题栏的“铺满工作区”按钮，铺满后切换成“还原面板”。使用跟随主题的单色线条图标和中英文提示。
- [x] 铺满主内容区时隐藏连接列表、终端和底部监控；应用顶部项目、已打开会话选择器、设置及工具窗右侧导航仍可使用。
- [x] 还原时恢复终端、侧栏、底部监控及原右侧分隔位置；不重新创建插件、文件浏览器或终端缓冲区。
- [x] 铺满后切换已打开会话：文件面板跟随目标会话，插件按插件 ID 匹配目标会话中已打开的页面，未打开该插件时回到目标会话插件列表。
- [x] 收起面板或关闭最后一个会话时退出铺满，恢复普通工作区。重复切换保留插件编辑器中尚未保存的内容。

当前入口属于 Swing 工作台，兼容其嵌入的原生 Swing 与旧 JavaFX 插件。无需插件 SDK 改动。文件导航和远程路径跟随逻辑继续由各会话自己的文件浏览器管理。

验证：`SwingToolWindowMaximizeTest` 在浅色和深色主题下使用真实窗口验证铺满面积、会话选择入口、还原分隔位置、不同插件页顺序的 ID 匹配、文件页跟随、编辑器保留、面板收起及最后会话关闭；文件布局夹具不建立远程连接。原终端保留及拖动行为由 `SwingWorkbenchDockTest` 回归。新增测试也加入 Preview 的 Windows UI 步骤。
