# 窗口透明与磨砂实现记录

目标是在 macOS 上实现可以看到其他窗口的背景透明和系统磨砂，默认关闭，并允许调节背景和终端的不透明度。前景文字、图标、选择区域与终端 ANSI 显式背景保持可读。

## 当前代码的约束

- `SwingWorkbench` 的根容器有实色背景；`IslandPanel.paint` 每次绘制时填充不透明圆角区域。
- `JlshellJediTermWidget.refreshVisuals` 把终端及其容器显式设置为不透明；JediTerm 自身还会在绘制时填充窗口背景。仅将 `JFrame` 设置成半透明并不能得到所需效果。
- 现有自定义窗口标题栏、分屏、重绘和插件宿主都必须继续工作；不能通过修改整个窗口的 opacity 同时淡化文字。
- 插件可能独立绘制 Swing 或 JavaFX 背景。宿主能够调整容器，但不能保证第三方插件内容自行透底。

## 实现边界与验收

1. 做原生背景独立原型：在 macOS 的正确线程上绑定窗口生命周期，接入 `NSVisualEffectView` 的 behind-window 材质，验证 Swing 表面、窗口阴影、缩放、多屏及关闭释放。透明模式不加载磨砂材质；关闭时不保留原生效果或动画。
2. 在该原型确认背景确实能穿过 Java 渲染表面之后，分层调整根容器、圆角面板及终端默认背景。保留显式 ANSI 背景、选中及光标；验证连续滚动、重绘残影、输入法、搜索和备用屏幕。
3. 在外观设置增加关闭、透明、磨砂和两项不透明度设置；设置走现有草稿、应用、取消、持久化与重启恢复流程，默认关闭。系统材质不承诺任意模糊半径。
4. 检查浅色和深色主题、原生窗口操作、弹窗层级与插件页面；测量关闭和开启后的启动、滚动和空闲资源占用。系统不支持或开启减少透明度时使用可读的实色背景。

当前尚未完成原生窗口桥接或设置界面；本文件不能视为功能已实现。
