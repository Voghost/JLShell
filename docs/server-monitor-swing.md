# 内置服务器监控的 Swing 呈现

2026-10-14。默认 Swing 工作台底部的服务器监控改为 `SwingServerMonitor`，移除该区域的 `SwingFxPanel`。

## 布局与行为

- 工具栏的连接名称为无交互的中性圆角标签，不绘制标签页下划线；标题区显示主机和操作系统、服务器时间、采样频率与更新状态；主机信息可点击查询系统详情。
- CPU、内存、网络、存储四组指标采用统一的数值、辅助信息、低对比背景与近期趋势。宽窗口四列，窄窗口两列或单列；默认工具窗高度 112px、最小高度 96px。紧凑状态把名称、数值、辅助信息放在同一行并隐藏趋势图；向上拉高后恢复分层数值及趋势图。较窄窗口需要多行时保留垂直滚动，辅助信息空间不足时省略并可悬停查看完整内容。
- 趋势保存本次会话最近 45 个采样点，时钟更新不会重复加入采样；这是即时趋势，不是持久历史。资源告警沿用既有阈值。
- 指标可点击查询原生 Swing 详情。CPU、内存进程表每 3 秒刷新，点击 PID 复制，关闭弹层停止查询；弹层按实际文本及进程行数计算高度。
- 紧凑指标使用统一字号与文本基线，仅指标标题加粗；更新说明复用现有 info-circle 图标，悬停显示，标题栏仅保留服务器时间和异常状态。
- 采集失败保留上次数据并明确提示，断开后标记为最后一次采样并禁用详情查询。

## 数据与线程边界

原有 `TerminalWorkspaceView` 保留 SSH 采集、解析、采样间隔和会话生命周期，发布不可变 `ServerMonitorSnapshot`。FX 线程将快照交给 EDT，Swing 只绘制和处理交互，不读取 FX 控件。原生视图关闭或重连替换时释放监听器、详情定时器与弹层。查询仅复用既有只读 SSH 命令。

JavaFX-only 回退路径保留旧状态条。独立的 `plugin-sysmon` 插件仪表盘及其他插件 SDK 视图不在本次迁移范围内。

## 验证

- `SwingServerMonitorTest`：深浅主题、窄宽布局、低高度滚动、更新失败/断开/关闭状态、进程解析；生成 `ui/target/review/server-monitor-*.png`。
- `SshWorkspaceUiSmokeTest`：模拟 SSH 输出走真实会话初始化、采样绑定和详情执行路径，断言监控区域无 JFXPanel、进程表内容正确；保留终端和侧栏原有回归验证。测试不连接真实主机或使用用户凭据。

2026-10-14 紧凑高度回归：工作台实际分隔条拖至最大位置后，断言底部不低于 96px，四组指标均隐藏图表、文字在一行完整显示且无多余滚动条；验证默认高度约 112px 与连接名称标签，截图见 `server-monitor-workspace-default/minimum.png`。
