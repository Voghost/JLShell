# 终端日志高亮

入口：**设置 → 终端 → 日志高亮**。搜索“日志高亮”也可找到终端设置。

默认开启，提供 ERROR/FATAL/SEVERE、WARN/WARNING、INFO、DEBUG、TRACE、SUCCESS/SUCCEEDED 规则。
默认只着色级别词，避免整行变色影响阅读。规则不区分大小写且匹配完整单词。

- 可以关闭全部高亮，也可以单独禁用某条规则。
- 选择规则后可编辑名称、关键词/正则、颜色和大小写选项。
- 编辑或新建后点击“保存规则”，再点击设置的“应用”或“确定”使所有已打开终端立即生效；取消会丢弃未应用的规则改动。
- 规则靠前者优先；“上移”可调整优先级。“恢复默认规则”仍需应用才保存。
- 示例文本可编辑，预览使用与终端相同的匹配器。无效正则不能保存到规则列表。

关键词示例：关闭“正则表达式”，输入 `连接失败`。
正则示例：`\b(?:timeout|timed out)\b`，或 `\b5\d{2}\b` 标记 HTTP 5xx。

## 显示与兼容

高亮只在 JediTerm 绘制文字时替换前景色，不修改 SSH 数据流、终端文本/样式缓冲区、复制内容或日志文件。
已有 ANSI 颜色、超链接、选中区域、搜索结果和反色光标优先。使用备用屏幕的 vim/top 等全屏终端程序不应用日志高亮。
本地终端和 SSH 终端均使用同一个应用级配置；字号、字体和终端网格继续由原有终端渲染器处理。

匹配按当前可见的显示行进行，支持同一行内跨 ANSI 样式段的关键词，以及包含中文宽字符的关键词。
自动折行边界两侧的关键词不会作为一整段匹配。预览用于查看规则颜色，不模拟终端已有 ANSI 颜色。

## 保存和性能

配置以 JSON 保存到应用设置 `terminal.highlight.rules`。旧版本没有此项时自动使用默认规则；损坏配置回退默认，不阻止启动。
不存在新增后台轮询或每字符数据库读取。只对当前可见行匹配；每个终端最多缓存 128 行，并限制缓存的文本/匹配区间总量；每行最多匹配 8192 个 UTF-16 字符。
最多 32 条规则，每条表达式 1–256 字符。每行匹配共享 100000 次字符访问预算；复杂规则超预算或栈溢出时停止该行后续匹配，避免拖慢输入。
配置变更通过弱监听通知已有终端重绘，关闭的终端不会被配置服务长期持有。
